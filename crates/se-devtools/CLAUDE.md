# se-devtools

## Purpose
Development tools, never shipped: today `generate-test-project`, behind `pnpm generate-test-project`, writes a large valid project folder (500 items by default) to try the timeline (prompt 10) and to measure performance (prompt 29). Nothing depends on this crate.

## Public API
- `generate-test-project [--out <folder>] [--items <count>] [--name <name>] [--seed <n>]` (defaults: `target/test-projects`, 500, « Projet volumineux », 1). Messages go to stderr; exit code 1 on failure. Prints the `.seproj` path to open with « Ouvrir un projet ».
- It generates six test media with the bundled ffmpeg into `<out>/media/` (kept between runs: four 1280×720 test-pattern videos with tones, a pink-noise music bed, a pulsing « voice »), probes them with `FfprobeProber` and fingerprints them like an import, then builds the document with the domain types (`project.rs`) and writes it with `FsProjectRepository::create`. A taken folder name gets a number (`Projet volumineux 2.seproj`).

## Rules and invariants
- The document is built from `se-domain` types and checked with `validate_project` before it is written: it always matches the current format (no hand-written JSON).
- Deterministic for a given seed (a 64-bit LCG): same layout, timings and source points; ids are fresh UUIDv7s.
- Layout: tracks V1–V3 and A1–A3; linked picture/sound clips on V1+A1 and V2+A2, texts and captions on V3, sound clips on A3, every ninth item made by a fake AI task (`Origin::AiTask`), twelve coloured markers spread over the sequence.
- Needs ffmpeg/ffprobe (`pnpm fetch-binaries`); thumbnails and waveforms are generated by the app when the project opens.

## Allowed dependencies
`se-domain`, `se-app` (ports, `media_paths::relative_hint`), `se-store`, `se-media`, `tokio`, `uuid`, `thiserror`. Like `se-codegen`, it is a leaf: nothing may depend on it.

## How to test
- `cargo test -p se-devtools` (the builder: requested item counts give valid documents; refusal of media without videos or sounds).
- `pnpm generate-test-project`, then open the printed folder in the app.
